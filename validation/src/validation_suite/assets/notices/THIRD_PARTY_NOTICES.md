# Third-party notices (validation tooling)

This validation suite can optionally download/build/run third-party software and models.
No third-party artifacts are committed to this repository by default; they are stored under `validation/workspace/`.

Projects referenced by optional validation steps:

- AMD ROCm docs (llama.cpp instructions): https://rocm.docs.amd.com/
- Ollama: https://github.com/ollama/ollama
- Open Interpreter: https://github.com/openinterpreter/open-interpreter
- OpenAI Whisper: https://github.com/openai/whisper
- MFEM: https://github.com/mfem/mfem
